The STM32MP257F System-on-Chip, a member of STMicroelectronics' MP2 family targeting embedded AI and multimedia applications. The SoC integrates heterogeneous processing elements on a single die:

Application CPU: Two ARM Cortex-A35 cores running at up to 1.5 GHz (32-bit ARMv8-A ISA, in-order pipeline). The A35 is optimised for area and energy efficiency rather than peak arithmetic throughput. Each core implements ARMv8 NEON SIMD (128-bit vector unit) and includes a 32 kB L1 data cache, 32 kB L1 instruction cache, and a 512 kB shared L2 cache. The two cores share a coherent interconnect to main memory.
Real-time coprocessor: One ARM Cortex-M33 core @ 400 MHz, used for deterministic low-latency sensor management, camera trigger control, and power management tasks that must not be preempted by the Linux scheduler running on the A35 cluster.
Neural Processing Unit (NPU): A dedicated hardware inference accelerator rated at 1.35 TOPS (INT8 peak throughput). The NPU is optimised for matrix-multiply-accumulate chains characteristic of convolutional and fully-connected layers (GEMM workloads). It operates on INT8 quantised weights and activations and is programmed via ST Edge AI Studio, which compiles ONNX or TFLite models to the NPU's native instruction set. The NPU shares the main memory bus with the A35 cluster and accesses LPDDR4 via DMA without involving the CPU data path.
GPU: Arm Mali-C55 ISP-class graphics processor. In this work the GPU is used for camera image signal processing (colour correction, demosaicing, noise reduction) rather than model inference, as the NPU provides a more energy-efficient path for INT8 neural network layers.
Video subsystem: DCMIPP (Digital Camera and Media Image Processing Pipeline), an ST-proprietary ISP with hardware crop, resize, and format conversion. The DCMIPP handles sensor-to-NPU data flow via DMA, enabling zero-copy frame delivery to the NPU input buffer without burdening the Cortex-A35 cores.
